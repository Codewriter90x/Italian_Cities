# Milestone 1 — historical record withdrawn

The data artifacts, checksums, normalization details and derived reports from
this milestone were withdrawn on 30 July 2026 because the project could not
establish the provenance and redistribution rights of the pre-clean-room
source material.

This document intentionally does not preserve paths, hashes, samples or
statistics from those artifacts. The supported dataset starts with the
clean-room `v2.0.0` build from the declared ISTAT and GeoNames snapshots.
