# Italian Cities v1.0.0

Prima distribuzione riproducibile dei dataset e dei formati derivati.

## Contenuto

- 7.186 comuni riconosciuti tramite snapshot ISTAT del 21 febbraio 2026;
- 7.294 località postali ancora non classificate;
- 14.480 associazioni luogo–CAP;
- 12.388 record con coordinate disponibili o corrette;
- 2.092 record senza coordinate.

Gli asset CSV, JSON, XLSX, SQLite e SQL rappresentano gli stessi record.
`SHA256SUMS` permette di verificarne l'integrità.

## Avviso su fonti e licenze

I codici e la classificazione comunale ISTAT provengono dallo snapshot
dichiarato nel repository e richiedono attribuzione CC BY 4.0.

La provenienza completa dei valori legacy originari, incluse molte coordinate,
non è dimostrata dai materiali storici disponibili. Il file `LICENSE` contiene
CC0 1.0, ma tale rinuncia opera soltanto sui diritti posseduti dall'autore che
la applica e non dimostra la titolarità su dati eventualmente importati.

La release è fornita “as is”. Prima di riutilizzare o redistribuire i dati in
un contesto rilevante, leggere
[`DATA_SOURCES.md`](https://github.com/Codewriter90x/Italian_Cities/blob/v1.0.0/DATA_SOURCES.md)
e verificare gli obblighi applicabili.

## Verifica

```bash
shasum -a 256 -c SHA256SUMS
```

Import SQL con SQLite:

```bash
sqlite3 italian_locations-from-sql.sqlite < italian_locations.sql
```
