# Italian Cities v1.0.0 — withdrawn

The downloadable dataset assets previously attached to this prerelease were
withdrawn on 30 July 2026 because the project could not establish the
provenance and redistribution rights of the pre-clean-room source material.

Do not redistribute archived copies as project-authorized data. Use the
clean-room `v2.0.0` release, built from declared ISTAT and GeoNames snapshots,
instead.
