# Italian Cities v2.0.0 — clean-room prerelease

This prerelease replaces the legacy-derived canonical dataset with a
reproducible build from:

- the complete ISTAT municipality snapshot dated 2026-02-21;
- GeoNames Postal Codes IT dated 2026-07-30.

Both sources are attributed under CC BY 4.0.

## Important warning

GeoNames is not Poste Italiane. Postal codes and coordinates are non-official,
provided without warranty, and must not be used as certified postal data.
GeoNames coordinates may be estimated algorithmically; the original
`accuracy` field is preserved.

`structural_quality` is `passed`, while
`operational_data_readiness` is `experimental_non_official`.

## Published statistics

- 7,894 ISTAT municipalities;
- 18,415 GeoNames source records;
- 18,811 postal-code relations;
- 8,095 exact, unambiguous GeoNames record matches;
- 0 ambiguous source-record matches in this snapshot;
- 10,320 unmatched GeoNames source records, represented by 10,270 localities;
- 396 municipalities without a GeoNames postal-code match.

## Breaking schema changes

Schema `3.0.0` separates municipalities, localities and many-to-many postal
relations. It adds source record IDs, reference dates, reconciliation method,
confidence and coordinate accuracy. Legacy UUID and legacy-derived quality
fields are removed from current outputs.

## Legacy

Legacy artifacts remain unchanged under `legacy/` and do not contribute to
the v2 canonical digest, outputs, release bundle or Pages data. The bounded
comparison report is investigative and does not prove the legacy source.
